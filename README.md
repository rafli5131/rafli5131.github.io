# Personal Engineering Portfolio

The source for [Rafliansyah's GitHub Pages portfolio](https://rafli5131.github.io/), showcasing selected public projects across AI engineering, robotics, backend development, and infrastructure.

## Design

- Single-page, responsive HTML/CSS.
- Sections: introduction, selected projects, engineering interests, and contact.
- Accessible page structure, keyboard-focus indicators, and reduced-motion support.
- No frontend framework or external JavaScript dependency.

## Local preview

```bash
git clone https://github.com/rafli5131/rafli5131.github.io.git
cd rafli5131.github.io
python -m http.server 8000
```

Open `http://localhost:8000` in a browser. The site is served from `index.html` with embedded styles.

## Deployment

GitHub Pages can publish directly from the default branch. Check repository **Settings → Pages** to verify the selected source and deployment status. A successful commit does not necessarily mean the public site has been published.

## Content notes

The portfolio links directly to external GitHub repositories. Project claims and links should be reviewed when those repositories change. Contact details are intentionally public in the website source.
